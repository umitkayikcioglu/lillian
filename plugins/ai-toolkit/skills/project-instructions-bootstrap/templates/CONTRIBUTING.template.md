# Contributing Guidelines

This file is owned by this repository. The Lillian-managed section below may be refreshed by `project-instructions-bootstrap`; text outside the managed section is maintained by the project.

<!-- BEGIN LILLIAN MANAGED: CONTRIBUTING -->
## Project Engineering Standards

Follow the repository's established conventions first. When this managed section is regenerated, it should contain only durable project information:

- selected engineering standards
- detected technology-specific standards
- verified validation commands
- scope and working-directory information
- stable tool conventions

Do not include transient evidence paths, rejected profiles, ambiguity reports, or unresolved recommendations in this file.

## Repository Scopes

List each detected project or workspace separately. Include the scope name and working directory for every verified command. Do not collapse unrelated applications into a single root command.

## Verified Commands

Only list commands discovered from declared scripts, project configuration, CI usage, or workspace configuration. Never list undeclared framework defaults as verified commands, and never translate package-manager scripts between npm, pnpm, Yarn, or Bun.

## Technology Standards

Include durable guidance only for profiles activated by definitive evidence. Do not add framework-specific rules for frameworks that were not detected.
